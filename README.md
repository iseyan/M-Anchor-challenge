## 逐次記録の方針

設計変更、設定の確定、実行、失敗・中断、再実行、解析が発生した都度、経過ログへ追記します。

各記録には、日付・時刻（JST、確認できた範囲）、変更内容と理由、使用した版と設定、実行範囲、結果、根拠ログへの参照、未解決事項と次の作業を残します。

確認できた事実、ユーザーからの報告、仮定、未確認事項を区別します。失敗や中断も保存し、過去の記録を後から成功したことに書き換えません。結果の訂正は、理由と根拠を付けて追記します。

モデル出力、ゲートの決定、実際の状態変更、下流への伝達を分けて記録します。計画上の「0件」と、実行して観測した「0件」を混同しません。認証情報や秘密情報は記録しません。
