# 正式シミュレーション仕様 v2（実行前に固定）

この仕様は、v2のシミュレーションを実行する**前**にコミットして固定する。実行後に設定・基準・選定規則を変えない。変える場合は v3 として別にコミットし、v2の結果も残す。v1の仕様・追補1・結果（不合格判定を含む）はそのまま残す。対象は分析計画v2（`analysis-plan-v2.md`）の主効果（周辺の率差）と、その区間・主検定・条件付きTOST・H5の手順である。

## 1. 生成器

v1の生成器（`analysis/simulate_intervals.py` の `setup`）を使い、次を加える（`analysis/sim_v2.py`）。

- 出力はケース単位（類型×状況×形式）で、送り手・条件ごとの3反復の観測数と陽性数を持つ。
- **二種類の帰無**：周辺の帰無（v1と同じ。C3だけ状況×条件の傾きの分散が0で、各条件の周辺率を較正）と、率もばらつきも等しい帰無（C3にも同じ傾きSDを置く）。生成器を検定に都合よく直して前者を消すことはせず、両方を残す。
- 境界・効果の設定（下表）。新設条件（C2・A1〜A3・C5）は v1と同じくC4と同じ率とする。
- 試行の観測できない判定：送り手別の完全無作為の欠測（gemma 5%、qwen 1%。初回試験の第2段階の呼び出し失敗 gemma 27/480 を参考にした仮定）を置く設定を加える。
- 真値の確認：各設定の真の率差（両送り手平均）を数値積分の較正値から求める。これとは別に、各設定で生成した全反復のケースをまとめた平均差（モンテカルロ）を記録し、|平均差 − 真値| ≤ 3標準誤差を確かめる。帰無の設定では、較正した目標率が条件間で厳密に等しいこと（差の絶対値 < 1e−9）も確かめる。確認に失敗した設定は生成器の不備として扱い、方法の合否には使わない（v3で直す。凍結を妨げる点）。

効果の設定（率は送り手ごと。基準は v1 の PILOT のC3）：

| 名前 | 内容 |
| --- | --- |
| null_m | 周辺の帰無（C3の傾き分散0） |
| null_e | 率もばらつきも等しい帰無 |
| plus / minus | C4 = C3 ± .03（GCはC3と同じなので、C4−GCも ±.03） |
| ni | 正当完了のみ。C4 = C3 − .05、GC = C3（C4−C3とC4−GCが −.05） |
| ni_c3c1 | 正当完了のみ。C3 = C1 − .05、C4 = GC = C3（C3−C1が −.05） |
| pilot | v1と同じ初回並みの率 |
| pilot_reweighted | 誤伝播・構造混合のみ。v1と同じ |
| sparse | 全条件の率 .02（疎な層の帰無） |
| sparse_plus | C3 = .02、C4 = .05（疎な層での +.03 境界） |
| pilot_gc_eq_c4 | 誤伝播のみ。初回並みのC3・C4、GC = C4（H4(a)に効果、H4′は帰無） |

## 2. 段階A：区間法の選定

候補：ケース単位の層別t（`case_t`、第一候補）と、状況単位の層別ジャックナイフ＋t（`jackknife_t`）。定義は分析計画v2の5節。

設定（各2,000反復）：傾きSD {0, .35, .7, 1.0} × `shared` .5、傾きSD .7 × `shared` {0, 1} の6通り。null_e は傾きSD 0 では null_m と同じなので除く。

| 系列 | 結果・構造 | 効果 |
| --- | --- | --- |
| M | 誤伝播・通常 | null_m, null_e, plus, minus, pilot, sparse, sparse_plus |
| MK | 誤伝播・構造混合 | null_m, null_e, plus, minus, pilot_reweighted |
| T | 試行・通常 | null_m, null_e, plus, minus, pilot, sparse, sparse_plus |
| TM | 試行・通常・欠測あり | null_m, plus, minus |
| L | 正当完了・通常 | null_m, null_e, plus, minus, ni, ni_c3c1, pilot |

基準に使う対比：M・MK は C4−C3 と C4−GC、T・TM は C4−C3、L は C4−C3・C4−GC・C3−C1。

**合格基準**（方法ごと。上の全設定・全対比で満たす。推定不能の反復は除かずに分母に入れる）：

| # | 基準 | 名目値 | 閾値 |
| --- | --- | --- | --- |
| A1 | 推定不能の割合 | — | ≤ .10 |
| A2 | 両側90%区間の被覆率（推定不能は被覆しないと数える） | .90 | ≥ .885 |
| A3 | 片側95%下限の被覆率（Lの3対比） | .95 | ≥ .935 |
| A4 | 区間だけの誤同等率：plus・minus・sparse_plus で90%区間が (−.03, +.03) の内側に入る割合（M・MK・T・TM の C4−C3） | ≤ .05 | ≤ .06 |
| A5 | 誤非劣性率：真値が −.05 の対比だけ（ni の C4−C3・C4−GC、ni_c3c1 の C3−C1）で、片側95%下限が −.05 を上回る割合 | ≤ .05 | ≤ .06 |

## 3. 段階B：主検定・Holm・条件付きTOSTの手順

誤伝播（H4(a)・H4′）と試行（H4(b)）を同じ反復で独立に生成し、分析計画v2の手順（推定不能の判定、Holm、TOSTのゲート）をそのまま適用する。両候補で実行する。傾きSD .7、`shared` .5（B2m・B2eは傾きSD 1.0でも実行）。各2,000反復。

| シナリオ | 誤伝播 | 試行 | 主な評価 |
| --- | --- | --- | --- |
| B1 | 構造混合・pilot_reweighted | pilot | 検出力、推定不能率 |
| B1s | 通常・pilot | pilot | 検出力、推定不能率 |
| B2m | null_m | null_m | 族の誤り（周辺の帰無） |
| B2e | null_e | null_e | 族の誤り（等分散の帰無） |
| B3 | plus | plus | 正式TOSTの誤同等（上側境界） |
| B4 | minus | minus | 正式TOSTの誤同等（下側境界） |
| B5 | sparse | sparse | 族の誤り（疎な層） |
| B6 | sparse_plus | sparse_plus | 正式TOSTの誤同等（疎な層） |
| P1 | pilot_gc_eq_c4 | null_m | 一部だけ効果：真の帰無（H4′・H4(b)）での族の誤り |
| P2 | null_m | pilot | 一部だけ効果：真の帰無（H4(a)・H4′）での族の誤り |

**合格基準**：

| # | 基準 | 閾値 |
| --- | --- | --- |
| B-1 | B2m・B2e（両傾きSD）・B5 で、3本のどれかが有意になる割合（Holm後） | ≤ .06 |
| B-2 | P1・P2 で、真の帰無の検定のどれかが有意になる割合（Holm後） | ≤ .06 |
| B-3 | B3・B4・B6 で、正式なTOST（H4ゲートあり、全反復が分母）が成立する割合（誤伝播・試行それぞれ） | ≤ .06 |
| B-4 | 全シナリオで、各検定の推定不能の割合 | ≤ .10 |

基準を置かず記録するもの：B1・B1s・P1・P2 の検出力（Holm後の有意な減少の割合）、B2m・B2e での正式TOSTの実施率と成立率、区間だけのTOSTの成立率、Lでの H5 の各比較と3比較同時の通過率、推定値の偏り、区間の平均幅。

## 4. モンテカルロ誤差の扱い

判定は2,000反復の点推定で行う。各確率に標準誤差（√(p(1−p)/2000)。.05付近で約 .0049、.90付近で約 .0067）を付ける。閾値は名目値から約2標準誤差の余裕をとった値で、上の表に固定した。閾値との差が2標準誤差以内の結果には「境界付近」と記すが、判定は変えない。判定を変えるために反復を追加したり、シードを変えて再実行したりしない。

## 5. 選定規則と最終確認

- 段階A・Bの全基準（A1〜A5、B-1〜B-4）を満たした方法のうち、`case_t` が満たせば `case_t`、そうでなく `jackknife_t` が満たせば `jackknife_t` を選ぶ。どちらも満たさなければ選ばず、本番へ進まず、独立ケース数と層の構成を見直す（凍結を妨げる点）。
- 選定用のシード：20261201（設定ごとに決まった番号を足す）。
- 最終確認：選んだ方法だけで、段階A・Bの全設定を、**別のシード 20261211** で各2,000反復実行し、同じ基準で判定する。1つでも満たさなければ凍結を妨げる点とし、方法を入れ替えて最終確認をやり直すことはしない。
- `config.json` の `interval_method` は、利用者が凍結を確定するまで書き換えない。

## 6. 記録

- 出力：`checks/simulation-v2-select.json`（両候補、段階A・B、真値の確認）、`checks/simulation-v2-selection.json`（判定）、最終確認は `checks/simulation-v2-final.json`。仕様のコミット、コードのSHA-256、Python・numpyの版を出力に含める。
- 補助解析のGLMMはこの仕様の対象外（判定に使わない）。
