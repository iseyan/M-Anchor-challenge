# v2シミュレーション（選定用シード）の結果：v2の基準を満たす区間法はない

仕様：`simulation-spec-v2.md`（`e4bcf7b`、コードより先にコミット）。コード：`analysis/sim_v2.py`・`analysis/rate_diff.py`（`bc319b1`、実行前にコミット。SHA-256は出力の `meta`）。選定用シード 20261201、各設定2,000反復。段階A 160設定、段階B 13シナリオ。所要1分48秒（2コア）。

- 出力：`simulation-v2-select.json`（全設定・全指標・モンテカルロ標準誤差・真値の確認）、`simulation-v2-selection.json`（判定）。
- 再現：`python -B -I analysis/sim_v2.py select checks/simulation-v2-select.json checks/simulation-v2-selection.json --reps 2000 --workers 2`
- 真値の確認：すべての設定で合格（較正誤差 < 1e−6、推定値の平均と真値の差 ≤ 3標準誤差、帰無の真値は厳密に0）。

## 判定

| 方法 | 満たさない基準の件数 | 内訳 |
| --- | --- | --- |
| ケース単位の層別t（第一候補） | 460 | 90%被覆 278、95%下限 105、区間だけの誤同等 51、誤非劣性 15、族の誤り 7、正式TOSTの誤同等 4 |
| 状況単位の層別ジャックナイフ＋t | 21 | 区間だけの誤同等 14、90%被覆 4、誤非劣性 2、正式TOSTの誤同等 1 |

**どちらも基準を満たさず、区間法は選ばれていない。** 仕様5節により最終確認用シードでの再確認は行わず、凍結を妨げる点として報告する。

## 読み取り

1. **ケース単位の層別tは、同じ状況の6ケースの相関を無視するため使えない。** 90%被覆の中央値は .777（最小 .574）、周辺の帰無（B2m）での族の誤りは .29〜.40。同じ状況のケースは状況×条件の効果を共有しているので、独立な単位は300ケースではなく、実質的に50状況（正当は30状況）である。
2. **状況単位のジャックナイフ＋tは、帰無と一部だけ効果の手順では基準を満たした。** 族の誤りは B2m .048・.046、B2e .038・.059、B5 .043、P1 .051、P2 .049。推定不能はすべてのシナリオで0。v1の B2（.35）で見えた尺度のずれは、率差を主対象にしたことで解消している。
3. ジャックナイフ＋tが満たさなかった点：
   - **疎な層での上側境界（sparse_plus、C3 .02 → C4 .05）**：区間だけの誤同等が .061〜.097（10設定）。下限の被覆は .96〜.97 と保たれている一方、真値が上限を超える割合が大きい。発生がまれなときに率差の分布が右に歪み、左右対称のt区間では上側が足りないためである。疎な帰無（sparse）で幅0の区間が誤って同等を出す現象はなかった（推定不能0、同等の成立はほぼ1で、真値0なので誤りではない）。
   - 試行の下側境界（minus、−3ポイント）：区間だけの誤同等 .0605〜.0655（4設定）、B4の正式TOSTの誤同等 .0645。v1の段階Aと同じ傾向で、閾値 .06 をわずかに超える。
   - 90%被覆 .8755〜.8845（4設定、閾値 .885）、正当完了 ni での誤非劣性 .0625（2設定、閾値 .06）。
4. 検出力（参考、ジャックナイフ＋t）：初回並みの効果（B1・B1s）では3本とも有意な減少が1.0。一部だけ効果（P1・P2）でも、効果のある検定は1.0。周辺の帰無（B2m、傾きSD .7）での正式TOSTの成立は、誤伝播 .19、試行 .61。

## 計画に沿った次の段階

分析計画v2の6節と利用者の方針（2026-11-19 18:32）により、区間法がv2の基準を満たさないので、本番へは進まず、**独立ケース数と層の構成を見直す**。検討の材料：

- 独立な単位は状況（攻撃50、正当30）であり、ケースを増やしても同じ状況の中では情報が増えにくい。状況の数（類型あたり5）を増やす案。
- 発生がまれな指標の上側の歪み：歪みに強い区間（変換した尺度での区間や非対称の区間など）を、v3の候補として事前に定める案。
- 基準そのものの見直し（例：疎な層の上側境界を基準に含めるかどうか）は、結果を見た後の変更になるため、行うならその旨を明記したうえで v3 として実行前に固定する。

いずれも設計の変更なので、利用者の判断を待つ。
