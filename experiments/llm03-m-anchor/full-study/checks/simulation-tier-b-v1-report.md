## 読み取り

1. **B1の推定不能率が .10 を大きく超えた**（H4(a) .475、H4′ .65）。仕様の規則により、凍結を妨げる点とする。原因は、qwen の C4・該当しない層がほぼ0になるセルでの非収束である。厳密な全0ではないので、当てはめ前の分離判定には掛からない。効果が大きいほど、計画どおりの主検定は判定を出せなくなる。
2. **B2の「帰無」は周辺の率の帰無で、GLMMが検定する条件付きの対数オッズ差の帰無ではない。** 生成器は C3 にだけ状況×条件の傾きの分散を置かず、各条件の周辺率を較正している。分散が違うと、周辺率が同じでも条件付きの対数オッズ差は0にならない。B2の H4(b) の平均 +0.62（率の差の平均は約0）と、B3 の大きな対数オッズ比はこの差による。したがって B2 の .35 は「条件付きの帰無のもとでの第1種の過誤」ではなく、「率が同じでも主検定は差ありと判定しうる」ことを示す。主仮説を率の差で読むか、条件付きの対数オッズで読むかが計画の中で揃っていない、という解釈上の問題である。
3. 正式な誤同等（B3、+3ポイント境界）は、どちらの対比でも 0/40 だった。ただし H4 のゲートでTOSTがほとんど実施されないための値で、区間だけの成立も 0 と .025 だった。下側境界（B4）は実行していない。
4. 真の差0（B2）での同等の成立は、誤伝播で .25、試行で .52 と低い。

## 利用者の判断が必要な点

- 非収束への対処：ペナルティ付き推定（blme など）、固定効果の単純化、層のまとめ方など。いずれも主検定の変更になる。
- 主仮説の尺度：条件付きの対数オッズ（現計画のGLMM）と、率の差（TOST・H5で使う尺度）のどちらで帰無を定めるか。シミュレーションの帰無もそれに合わせて作り直す必要がある。
- 正式な精度での段階B（反復数の増加）とB4の実行。区間法が決まってから行う。
