- **gemma3 の分割は不完全である。** 13:27:27 に Ollama が 0.40.16 から 0.40.17 に更新されて再起動し（開始時の環境確認は2分割とも 0.40.16、終了後の確認で 0.40.17）、以後の接続がすべて失敗した。残りの22試行の初期評価が約5秒で再試行を使い切り、110エピソードが未実行になった。自動更新によるものと見ているが、更新の記録そのものは確認していない。
- qwen3 の分割では、開始約1分後に Playwright のページが一度リセットされた。ループを入れ直し、送信中だった1件は TRANSPORT_LOST として記録され、再試行で回復した。
- gemma3 の完走分では、token repeat limit の HTTP_ERROR が7回あり、2件が再試行を使い切った。
- 対応：Ollama を 0.40.16 に入れ直し、トレイアプリを使わず `ollama serve` で起動する。接続できない呼び出しが出たら分割を止める仕組みを `runner/run3.py` に加えた（`guarded_call`）。gemma3 の分割は新しい実行フォルダでやり直す。この回の記録は残す。
